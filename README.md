## Воспроизведение финального ансамбля

```bash
git clone https://github.com/sufa01/rexis.git
cd rexis
python3 -m venv .venv
source .venv/bin/activate
python -m pip install pandas numpy scipy scikit-learn implicit
bash run.sh
```

Итоговый файл: `submission.csv`

Скрипт последовательно запускает EDA и базовую валидацию (роль 1), обучает классические модели и формирует кандидатов (роль 3), затем объединяет их с готовыми предсказаниями SasRec (роль 2) через RRF (роль 4). Используются веса SasRec 2, seq_ease 1 и EASE 0.25.

Важно: это воспроизведение финальных предсказаний, а не полного процесса обучения SasRec с нуля. CSV SasRec сохранены в `role4_inputs/`

На использованной командой локальной валидации Recall@10 ансамбля составлял 0.305298; публичный результат Kaggle = 0.2935. Эти значения не означают, что каждый повторный запуск классических моделей обязательно выдаст побитно идентичный результат на другом оборудовании.
